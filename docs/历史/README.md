# 历史文档

这个目录存放**已完成使命、但仍有追溯价值**的文档。

判断标准很简单：文档里描述的方案、模块列表或技术选型，**如果照着做会写错代码**，
那它就该在这里，而不是在 `docs/` 根下。放在这里的文件只用来回答
「当初为什么这么决定」，不用来指导当前的开发。

## 当前内容

| 文件 | 是什么 | 为什么还留着 |
|---|---|---|
| `开发计划.md` | 项目起步时的需求构想（2026-10-16） | 记录了最初的模块设想与「复刻 .NET 版 Kugua」的出发点。现在模块清单和定位都变了，但能查到某些设计取舍的源头。 |
