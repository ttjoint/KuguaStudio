# 知识库设计（MKG）

> 苦瓜知识图谱（Momordica Knowledge Graph，MKG）是苦瓜工作室的数据层。
> 本文定义数据模型、标签持久化（侧车）、检索（FTS5）、智能视图与位置管理。
> 背景与整体架构见《架构设计.md》。

## 一、目标

用"标签图 + 全文检索"补足 Windows 资源管理器的短板：

- 一个文件可同时属于多个类目（网状），而非只能放进一个文件夹（树状）；
- 能按标签组合、否定、类型快速筛选，并把常用筛选**保存**下来；
- 能检索文件内容，而不只是文件名；
- **不搬迁、不破坏**原始文件；文件被移动后标签尽量不丢；
- 统一管理图片、多媒体、文本段、学术资料、点子、记事卡片，并以工作区画布自由编排。

## 二、核心决策

| 决策 | 取舍 |
|---|---|
| 文件系统为真源 | MKG 只存索引与标签；数据库损坏可由文件重建 |
| **侧车持久化标签** | 参考 TagSpaces：标签写入文件旁的 `.mkg.json`，可随文件迁移；DB 为缓存与查询加速 |
| 不使用"文件名内嵌标签" | 与导入重命名/去重逻辑冲突，最多支持只读解析 |
| SQLite 单文件 | 零运维；用 FTS5 做全文、用普通表做标签与关系 |
| 统一节点模型 | 文件/目录/笔记/素材/文本段/卡片共用一个 `nodes` 实体，标签与关系挂在节点上 |

## 三、数据模型

### 3.1 节点（统一实体）

```
nodes(
  id, type, title, created_at, updated_at, meta
)
type ∈ { file, directory, note, material, card, snippet }
```

- `file/directory` 通过 `resources.node_id` 关联真实路径；
- `note/material/card/snippet` 的正文各自存于内容表；
- `meta` 存扩展信息（如素材来源、看板列、侧车路径）。

### 3.2 标签

```
tags(
  id, name, parent_id, description,
  color,       -- 新增：颜色 #RRGGBB
  kind,        -- 已废弃：曾计划 plain|arrow|group|smart，未实现读写，列保留仅兼容旧库
  icon,        -- 新增：图标
  sort,        -- 新增：排序
  created_at
)
node_tags(node_id, tag_id, created_at)
```

- `parent_id` 表达层级（标签树）。
  （`kind=group`/`arrow`/`smart` 等设想已废弃——该列与类型定义均不再使用；
  标签树的层级现仅由 `parent_id` 表达，分组/箭头/动态生成等需求若有，应另立字段。）

### 3.3 关系

```
node_relations(from_node_id, to_node_id, relation_type, created_at)
relation_type ∈ { contains, references, similar, ... }
```

### 3.4 全文检索（FTS5，新增）

```
-- 文件/节点标题与正文
CREATE VIRTUAL TABLE node_fts USING fts5(
  title, body, tokenize = 'unicode61'
);
-- 由触发器或写入逻辑同步 nodes/内容表
```

- 中文检索：优先使用 `unicode61` + 应用层分词/ngram；若 FTS5 支持 trigram 可切 `trigram`；
- 文件文本内容沿用 `text_contents`，纳入 `node_fts.body`。

### 3.5 保存视图（新增）

```
saved_views(
  id, name, query, icon, sort, created_at
)
-- query 形如：
-- { "tags": [12, 30], "notTags": [7], "type": "image",
--   "text": "雪山", "locations": [1], "sort": "updated" }
```

保存视图即"智能文件夹"：点击后等价执行一次组合查询，不复制任何数据。

### 3.6 位置（新增）

```
locations(
  id, path, name, mode, excludes, created_at
)
-- mode ∈ { watch, manual }
-- excludes 为 JSON 数组（glob/正则）
```

### 3.7 记事栏（看板）

`type=card` 的节点组成看板：列存于 `card_columns`，卡片正文存于 `card_contents`；
卡片的 `columnId` / `color` / `sort` 存于 `nodes.meta`。卡列可重命名、卡片允许跨列拖拽。

```
card_columns(id, name, sort, created_at)
card_contents(node_id, content)
```

### 3.8 工作区（画布）

工作区是 ComfyUI 式的自由画布，**只保存对节点的引用与摆放位置，不复制任何资源数据**；
删除工作区或放置项**不会**删除被引用的节点。

```
workspaces(id, name, sort, created_at, updated_at)
workspace_items(id, workspace_id, node_id, x, y, width, height, color, note, created_at)
```

- `workspace_id` / `node_id` 均为外键，级联删除；
- `x/y/width/height` 为画布坐标与尺寸，`color`/`note` 为展示用便签。

位置 = 受管根目录。支持多个，各自可有排除规则与扫描策略。

## 四、侧车（Sidecar）规范

### 4.1 位置与命名

对文件 `<目录>/<名字>.<扩展>`，侧车为：

```
<目录>/<名字>.<扩展>.mkg.json
```

- 与文件同名同级，`资源管理器中可见`（便于手动检查）；亦支持隐藏目录模式 `.mkg/<名字>.<扩展>.json`（可配置）。
- 目录类型资源使用 `<目录名>.mkg.dir.json`。

### 4.2 内容

```jsonc
{
  "version": 1,
  "sha256": "…",                 // 用于判断文件是否被替换
  "tags": ["旅行", "雪山"],       // 标签以"路径"形式存储，跨库可移植
  "relations": [
    { "type": "references", "target": "../论文/雪山构造.md" }
  ],
  "note": "拍摄于…",
  "updatedAt": 1700000000
}
```

- **标签按名称/路径存**，不存数据库 id，保证换机器可重建；
- `sha256` 用于冲突判断；
- 关系用相对路径引用，尽量可移植。

### 4.3 一致性规则

- **写穿**：任何在应用内修改标签/关系的操作，先写 DB，再写侧车（或反之，二选一并保证幂等重试）。
- **谁赢**：以文件 `mtime` 与 `sha256` 判断——侧车 `sha256` 与当前文件不符时，视文件已变更，触发重新索引；
  侧车 `updatedAt` 与 DB 记录不一致时，取较新者。
- **重建**：提供"从侧车重建数据库"与"从数据库导出侧车"两个动作。
- **可选**：启动时可对已配置位置做增量扫描，发现无侧车的文件不强制创建。

## 五、与资源管理器的关系

- 支持按目录浏览（保留树状），同时提供标签树、智能视图、搜索三种网状入口；
- 右键菜单：从知识库移除（只删记录）/ 删除到回收站（删物理文件）/ 复制路径 / 在资源管理器中打开；
- 按扩展名配置打开方式（`open_with_config`），可注册为插件式 Viewer/Editor；
- 批量操作：框选、Ctrl/Shift 多选、批量打标/移除。

## 六、迁移与初始化

1. 现有数据库内容为临时测试数据，**允许直接重建**；
2. 新库直接按本设计初始化，无需兼容旧结构；
3. 迁移策略：若检测到旧库，提供 `mkg.rebuild`，丢弃旧标签并重新扫描位置，侧车优先。

## 七、接口（能力）草案

| 能力 | 说明 |
|---|---|
| `mkg.search` | 组合查询（标签/否定/类型/文本/位置/排序） |
| `mkg.view.save` / `mkg.view.list` / `mkg.view.delete` | 保存视图 |
| `mkg.location.add` / `list` / `remove` / `scan` | 位置管理 |
| `mkg.sidecar.read` / `write` / `export` / `import` | 侧车读写与重建 |
| `mkg.node.*` `mkg.note.*` `mkg.snippet.*` `mkg.material.*` `mkg.card.*` | 现有节点族能力（沿用） |
| `mkg.workspace.list` / `create` / `update` / `delete` | 工作区增删改查 |
| `mkg.workspace.items` / `itemAdd` / `itemUpdate` / `itemRemove` | 工作区放置项（引用节点 + 坐标） |
| `mkg.fts.rebuild` | 重建全文索引 |
