# 模块复刻清单（待批准）

> 目的：移除历史实现，按新模块写法（**能力声明 + 处理**）复刻功能。
> 依据：《功能复刻准则.md》《架构设计.md》。
> 本清单需项目所有者批准后，才逐项执行"移除旧实现 → 按新写法复刻"。
>
> **阅读说明**：第二至六节保留的是**最初评审时的计划与批注**（“现有 JS”列为当时快照，
> “处置”列为当时决定），不随实现推进而回改；**各项当前完成状态以第九节「执行进度」为准**。

处置标记：

- **保留**：平台自研基础设施，非复刻，继续维护；
- **复刻**：从 C# 忠实迁移（算法/语法/映射表严格一致，禁止简化）；
- **重写**：已有 JS 实现，但按新写法（能力声明、统一入口）重做；
- **待测**：依赖外部在线服务，先测可用性再定；
- **延后**：实现但优先级低，或等核心稳定后再做；
- **不做**：按《功能复刻准则》排除。
