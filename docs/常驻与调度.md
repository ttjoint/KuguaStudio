# 常驻与调度

> 本文件说明如何让苦瓜工作室常驻后台、登录/开机自启、执行启动任务与管理系统日志。
> 操作脚本见 `scripts/service/README.md`。

## 一、常驻运行的两种方式

### 1. 登录时自动启动（推荐）

用 Windows 计划任务，在用户登录后隐藏启动 WebUI（WebUI 托管主控与全部模块）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\service\install-logon-task.ps1
# 指定端口： ... -Port 24600
# 立即启动： Start-ScheduledTask -TaskName KuguaStudio
# 移除：     ... scripts\service\uninstall-logon-task.ps1
```

- 以当前用户身份运行，`node` 需在 PATH。
- 配置了崩溃重启（3 次 / 间隔 1 分钟）。
- 启动参数带 `--no-open`，登录时不弹浏览器。

### 2. 注册为 Windows 服务（无用户登录也运行）

使用 [WinSW](https://github.com/winsw/winsw/releases)：

1. 下载 `WinSW-x64.exe`，重命名为 `kugua-webui.exe` 放到项目根；
2. 复制 `scripts/service/kugua-webui.xml` 到项目根；
3. 管理员执行 `.\kugua-webui.exe install` / `start`。

模板已配置崩溃自动重启与按大小滚动日志。

## 二、启动 / 登录任务（调度）

调度模块支持 `触发: "startup"` 的任务：**平台启动后执行一次**（不参与 cron 排程）。

- 中文指令：`添加启动任务 <名称> <模块> <动作>`
  例：`添加启动任务 每日索引 mkg fts.rebuild`
- 结构化调用 `scheduler.task.create`：
  ```jsonc
  { "name": "启动自检", "触发": "startup",
    "action": { "kind": "request", "to": "monitor", "action": "monitor.stats" } }
  ```
- 执行结果记录在任务的 `lastResult`，可在 WebUI / `scheduler.task.list` 查看。

可选桥接 Windows 任务计划程序（把系统级定时任务交给 OS）：使用计划任务脚本或 `schtasks`，本平台侧仍可用 cron 任务覆盖多数场景。

## 三、日志

| 类型 | 位置 | 说明 |
| --- | --- | --- |
| 主控/模块日志 | 内存环形缓冲（默认 4000 条）+ `data/logs/main.log` | 限流落盘：仅在有内容时批量追加，空闲不写盘 |
| 作业日志 | `data/jobs/<id>.log` | 见《架构设计.md》第五节 |
| 应用内通信日志 | WebUI Debug 面板 | 苦音总线收发记录 |

- 环境变量 `KUGUA_LOG_FILE` 可覆盖主控日志文件路径。
- 查询动作（`nigane`）：`log.tail`（按模块/级别/关键词/时间过滤）、`log.stats`、`log.clear`。
  例：`log.tail` 参数 `{ "模块": "mkg", "limit": 100 }`。

## 四、资源约束

- 空闲时不产生周期性磁盘写：调度器为内存勾选、状态变更才落盘；日志器仅在有待写内容时落盘。
- 内存缓冲固定容量，避免无限增长。
- 作业并发有上限（`job.maxConcurrent`，默认 4）。
