# 杀毒软件误报说明

苦瓜工作室是本地运行的个人工具，**不含任何恶意代码**。但它的若干行为在杀软的
启发式规则里与恶意软件高度重合，因此可能被 Windows Defender 或第三方杀软报毒。

本文记录触发特征、已做的降噪处理，以及你遇到误报时该怎么办。

---

## 一、哪些行为会触发误报

| 行为 | 在哪里 | 为什么像木马 |
|---|---|---|
| PowerShell 脚本常驻运行 | `packages/webui/tray.ps1` | 托盘图标靠一个常驻 PowerShell 进程维持 |
| 创建登录计划任务 | `scripts/service/install-logon-task.ps1` | `schtasks` 建自启动任务是**持久化**的典型案例 |
| 强制结束进程 | `tray.ps1` 的「退出」 | 结束进程树是木马的常见收尾动作 |
| 隐藏窗口启动子进程 | `start.bat`、后台启动 | `-WindowStyle Hidden` + `Start-Process` 是隐蔽执行的经典组合 |
| 拉起任意可执行文件 | 模块 / 外部程序接入 | 插件能 spawn 任意命令，行为上等同于加载器 |
| 单文件免安装 + 本地监听端口 | 桌面端壳 + WebUI | 「无签名 + 开端口 + 常驻」是老式后门的画像 |

单独看每一条都不致命，但**组合起来**（常驻 + 持久化 + 结束进程 + 隐藏窗口 +
开端口）恰好凑齐了杀软规则的多个特征，所以有误报并不意外。

---

## 二、已做的降噪处理

1. **`-ExecutionPolicy Bypass` → `RemoteSigned`**
   `Bypass` 是恶意脚本绕过执行策略的标准手法，是误报率最高的单个特征。
   本地脚本在 `RemoteSigned` 下本来就允许执行，功能完全不受影响：

   ```powershell
   # 之前（高误报）
   powershell -NoProfile -ExecutionPolicy Bypass -File tray.ps1

   # 现在
   powershell -NoProfile -ExecutionPolicy RemoteSigned -File tray.ps1
   ```

2. **`taskkill /PID x /T /F` → `Stop-Process -Force`**
   调用外部命令并强制结束，比用 PowerShell 原生 cmdlet 更容易命中规则。

3. **所有 `spawn` 显式带 `windowsHide: true`**
   不再依赖「先隐藏窗口」的写法，减少「隐蔽执行」特征。

4. **不写入系统目录、不修改注册表**
   计划任务仅在你**主动点击**托盘菜单的「开机启动」时才创建，可随时取消。

## 三、被误报时怎么办

### 方案 A：加 Defender 排除目录（推荐）

以管理员身份运行 PowerShell：

```powershell
Add-MpPreference -ExclusionPath "D:\Projects\KuguaStudio"
```

撤销：

```powershell
Remove-MpPreference -ExclusionPath "D:\Projects\KuguaStudio"
```

### 方案 B：检查隔离记录

若已被隔离，到 **Windows 安全中心 → 病毒和威胁防护 → 保护历史记录** 找到对应项，
选择「允许在设备上」。

### 方案 C：自行验证可疑行为

不放心的话，先搜代码再看：

```bash
# 所有 spawn / exec 调用点
grep -rn "spawn(\|execFile(\|exec(" packages/*/src packages/modules/*/src

# 所有网络监听
grep -rn "\.listen(" packages/*/src

# 所有计划任务操作
grep -rn "schtasks" .
```

平台**只监听 `127.0.0.1`**，不对局域网或公网开放；不主动向外发起连接
（除你自己配置的 AI / TTS 服务端点以外）。

## 四、若你打算打包分发

给他人分发时误报会明显增多（陌生人下载的未签名二进制）。可选手段：

- 给可执行文件做代码签名（需购买证书）
- 提交误报：<https://www.microsoft.com/en-us/wdsi/filesubmission>
- 发布时附上本说明与源码地址
